# Android安装兼容修复独立评审

2026-11-14，维护者已明确允许独立子代理交叉评审。本次复用独立平台评审者，只读检查修复分支的安装交接、保存恢复及对应故障注入测试，不读取签名材料、真实笔记或私有运行目录。

发现并完成修正：

- Activity结果和返回前台不能证明安装成功，改为核对系统实际versionCode；未知结果保留等待与明确取消入口。
- 每次交接使用独立attempt、文件和Activity Result键，拒绝旧回调影响新尝试；处理注册时同步回放，避免残留旧launcher。
- FileProvider使用独立子类、非导出专用cache路径和单文件读取授权；接受合法canonical父路径别名，拒绝逃逸与叶子符号链接。
- 撤销授权、删除缓存或写入安装记录失败不能跳过core恢复；持久化清理票据，恢复失败保留重试。
- 原生更新失败记账与core恢复分开执行，前者异常仍尝试恢复；后者失败不误报编辑已恢复。
- 完整系统确认Intent只保留在存活进程内，不再经URI序列化往返；进程重建不启用缺失对象的“继续”。
- 持久记录的IO完成后重新获取Activity并检查生命周期，避免旋转或后台期间捕获的旧Activity启动安装。

最终只读复核未发现剩余阻断项，确认新增测试保留了屏障、正文与重试断言。评审者没有运行本轮构建或设备测试；主代理实际执行与未验证范围见[验证记录](../android-install-compatibility-validation.md)。模拟器通过不代表Civi或所有厂商设备已通过。
