## 发现与处理

发现一项阻断：HTTP 已认证旧会话后，同设备重新登录可能替换 token；旧请求继续执行 `revoke` 时只按账号/设备更新，会吊销新会话。已在 `ab1886c` 修复：同一写事务内重新校验操作方的 token_hash、有效期和撤销状态，再执行更新；新增旧 identity 对自身及其他设备吊销均拒绝、新 token 仍有效的回归。vet/lint/race 与真实核心联调均通过。

另核对修复 `ad1a336`：只有 Markdown 标题标记而无文字时，导出 manifest 统一使用“无标题”，与核心一致；函数和真实 ZIP 边界测试通过。服务端库覆盖率更新为 75.2%。

## 核对内容

- 密码使用带随机盐的 Argon2id，token 和邀请码只存哈希；注册消费邀请码及创建账号/设备在同一事务，登录重新核对密码哈希以防并发管理员重置。
- push 每项事务内复验凭据，操作幂等结果、权威笔记、序号和不可变变化记录同批提交；冲突保留已有权威版本并新建副本，通知在提交后发送。
- 所有笔记、变化、幂等与设备查询均限定账号；错误消息不直接输出 SQLite 错误或输入正文。JSON、UTF-8、计数器、大小和协议边界有真实测试。
- epoch 独立于数据库且受服务锁保护；旧库缺元数据时拒绝静默初始化。备份用 SQLite 一致快照，恢复后轮换 epoch，拒绝继续使用旧同步历史。
- SSE 使用认证头、初始信号、心跳及周期凭据复验；无 CORS，生产仅允许回环监听和可信 HTTPS 反向代理。
