# 0.1.8 账号与跨端交互独立复核

维护者明确授权本轮独立子代理评审。两名评审者只读查看源码，不访问签名材料或真实笔记；范围为账号表单/保存屏障及三端控件、更新页面和官网生成。不是同步协议/schema变更评审，也不代表目标设备验收。

账号复核发现并修正：Android重新登录仅用布尔值、切换空间可能改目标，现捕获原profile ID并在变化时放弃旧意图；两端仅在明确成功回执与刷新后的当前空间一致且不是auth_required时收起；普通添加账号的服务器草稿与只读重新登录表单分离，失败不误报成功。Android跳过busy期间轮询，并通过请求代次拒绝迟到快照。原flush→core→refresh顺序、注销保留本地数据、恢复空间只读保持。

账号评审者最终静态复核未发现剩余阻断项；独立运行Svelte检查0错误/0警告，回执单测2通过。没有由该评审者运行Android设备测试。

平台复核发现：桌面组件重挂载会丢失更新命令pending、缺target错误快照被当Linux；Android展开的偏好菜单未禁用且偏好/主操作可并发。实现已改为共享命令屏障、明确system-managed目标、失效菜单收起和偏好/主操作互斥，取消下载信号及系统确认/取消保留。官网浏览器检查增加真实语言与渲染版本断言，附件公开下载另行核对。最终复核与实际执行结果继续记录在[发布验证](../releases/0.1.8-validation.md)，未运行项不能据本文件宣称通过。

平台后续复核另发现原生后台自动检查不受前端store约束，现补桌面原生RAII共享gate，覆盖定时检查/下载、IPC与安装，snapshot提供operation_pending，生命周期读取统一为Arc状态。最终评审确认忙碌拒绝、错误/JoinError恢复和gate释放，取消/snapshot可用且无新增阻断项；评审者未运行构建/设备UI。根代理实际执行的三项gate回归与两端构建另见发布验证。core与服务端实现未变。
