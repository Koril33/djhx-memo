# 国际化、主题与品牌增量交叉评审

- 日期：2026-11-07 至 2026-11-08。
- 范围：[产品规范第 10 节](../../spec/product-v1.md#10-品牌语言外观与时间显示)；桌面与 Android 的语言、明暗主题、显示时区、默认服务地址、应用名、统一图标，以及 Windows 改名覆盖安装。
- 分工：桌面、Android、品牌分别由独立协作者实施；品牌协作者审阅桌面展示与 NSIS，Android 协作者复审桌面错误呈现；整合者审阅 Android 展示、资源与仪器断言，并执行 Ubuntu 原生 GUI 检查。此记录不替代既有同步、迁移、鉴权评审。

## 发现与处理

| 发现 | 修正与证据 |
| --- | --- |
| 文本乘号的字体基线导致设置关闭按钮裁切 | 桌面使用固定 36px 点击区域内的 SVG，并有本地化可访问名称与焦点；Ubuntu 实际中英文、浅深主题下完整显示，点击只关闭设置 |
| Android Dialog/下拉窗口缓存初次语言 | 显式向独立窗口提供最新 Context/Configuration；实际点击设置选项的仪器测试确认切换后对话框和选项即时翻译 |
| GNOME 已设深色，但 GTK3/WebKit matchMedia 返回浅色 | Linux 原生只读 portal 优先、gsettings 回退，系统模式异步轮询，显式选择优先；Ubuntu 实际切换系统深/浅时，应用及标题栏一同更新 |
| NSIS 产品改名会改变旧安装注册表身份与路径 | 保留旧安装身份与默认目录，显示名和新入口使用 DJHX Memo；没有改变应用标识、数据目录或凭据服务标识 |
| NSIS 更新模式若先删旧快捷方式，可能没有新入口 | 改为校验目标后重命名；目标已存在或移动失败保留旧入口，错误不阻断安装；修复经独立复审 |
| Android 用户名校验说明遗漏连字符和首位约束 | 两语文案与既有鉴权规范对齐，补充资源契约断言；未改变鉴权规则 |
| 桌面未知错误码会原样附在固定译文后；普通对象映射可能命中原型键 | 未知错误只显示通用译文，两张错误映射均仅接受自身键；新增双语回归覆盖未知码、长字符串、中文载荷及 constructor/toString/__proto__ 等路径 |
| 桌面英文数量原先固定复数，出现 1 notes / 1 characters | 为全部 8 个数量键提供类型检查的单数模板，经 Intl.PluralRules 选择；回归覆盖 1/0/2、格式化数量字符串与中英插值参数一致，Android 沿用资源 plurals |

## 复核结论与边界

桌面语言、主题和时间格式只作用于展示。编辑器通过 CodeMirror compartment/CSS 更新，不按语言或主题销毁实例；Android 更新原生编辑器属性，仪器断言检查同一 EditText、正文及组合输入 span 保留。两端均未引入另一套同步规则，未修改 core、server、迁移或凭据身份。

图标从一份可编辑 SVG 生成，设计板、尺寸、ICO、Android 分层 XML 与哈希清单一并提交；生成器检查不能替代设备上的启动器验收。NSIS 模板来源和 MIT 原文已保留，开发期图标工具版本与许可证见 [ADR-0010](../adr/0010-brand-assets.md)。

实际构建、最终包哈希、覆盖安装和各系统 GUI 结果以 [桌面验证](../desktop-validation.md) 与 [Android 验证](../android-validation.md) 为准。物理 arm64、API 29、Windows 11、完整输入法/系统组合、三端同账号 GUI 矩阵与连续 7 天试用仍未完成，不据本次展示评审宣称 v1 已发布。
