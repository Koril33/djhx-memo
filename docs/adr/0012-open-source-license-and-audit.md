# ADR-0012：MIT 授权与开源前本地审计

- 状态：按项目负责人要求采用。
- 日期：2026-11-08。

为便于他人学习、修改及复用，原创代码与文档统一采用 MIT；不附禁止商用条款。根 LICENSE 为授权原文，包内同时携带项目许可和既有第三方通知；详细边界见[许可证说明](../licensing.md)。维护者明确选择保留原作者身份和完整 Git 历史；不因本轮整理改写历史或更改远端可见性。

密钥检查使用固定 Gitleaks 8.30.1（MIT），来源为[官方发布](https://github.com/gitleaks/gitleaks/releases/tag/v8.30.1)，执行前核官方 SHA256。该版本仍由上游提供，项目已宣布功能完备、后续以安全补丁为主；这里只作为可替换的可选本地审计工具，未加入 npm/Cargo/Gradle/Go 运行依赖，也不部署 CI/Runner。配置保留默认规则并对两处已核非秘密文字作精确例外，执行入口、范围和限制见 [SECURITY](../../SECURITY.md)。升级工具或扩展例外时要记录原因及有效的检出验证。

公开开发文档按任务和平台组织，不以维护者机器配置、可访问 VM、真实账号、已生成 JNI 或私有签名文件作为前提。AI 仍遵守同一 spec、模块边界、有效测试和独立评审约束；发布准备检查不代表 v1 运行验收已完成。
