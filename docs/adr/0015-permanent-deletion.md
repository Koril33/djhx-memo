# ADR-0015：单条彻底删除与同步协议 2

- 日期：2026-11-11
- 状态：维护者批准产品范围；实现的独立同步/迁移交叉评审仍待完成
- 行为事实来源：[增量契约](../../spec/permanent-deletion.md)

采用单条确认、持久化删除请求、服务端回收站版本校验、不可逆永久标记。普通 outbox 保留已有不可变快照；待确认普通删除先完成，再绑定其确认版本发出彻底删除。账号同步继续由 Rust core 协调，不在界面实现版本规则。

彻底删除使用独立 HTTP 接口，避免改变普通写入的幂等指纹。Note 增加 purged；本地增加 purge_state 和 purge_requests，服务端增加 purged 字段，全部追加迁移。永久删除标记覆盖旧待发编辑，服务端禁止复活及自动生成冲突副本。未提交的 UI 输入只能经明确救援操作保存成新 ID。

协议版本升为 2，保留 /v1 路径；写入、拉取、通知、云导出与彻底删除要求 X-Memo-Protocol: 2。旧客户端停止同步并提示升级。新客户端不自动降级到协议 1，避免忽略永久标记；需配套部署服务端。不得修改既有 Release 或移动 tag。

当前正文清空，产品列表/搜索/导出不返回永久删除笔记。既有变化快照、迁移副本、恢复空间、备份及用户导出不追溯清理。管理员恢复删除前的旧备份可能包含旧内容，不能据此承诺跨灾备安全擦除；最小标记正常运行时不清理。本次不提供批量、自动清理、全部云数据擦除或新依赖。

Windows 复用保存生命周期处理托盘切换；Linux 保留菜单恢复。列表折叠为本机展示偏好，保留编辑器和全部编辑状态。

本轮主机只验证 Windows/Android。为在 Windows 运行真实 Go HTTP 业务测试，SQLite 文件 URI 规范化为跨平台路径；Unix epoch 文件锁、CLI 与部署支持范围不变。可通过 Go 显式源文件测试业务包并与 Rust 客户端联调，不以此声称完整 Windows 服务端或 Linux 桌面验收。
