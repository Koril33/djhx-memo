## 证据与限制

本机原始日志为 `.local/android-0.1.3-native.log`、`android-0.1.3-check.log`、`android-0.1.3-core-highlight.log`、`android-0.1.3-highlight-probe.log`、`android-0.1.3-canonical-test-build.log`、`android-0.1.3-full-device.log`（同名 JSON 含逐项结果）及 `android-0.1.3-real-ime-device.log`。`.local/android-0.1.3/` 另保存构建输入来源、签名、对齐、ELF、许可、安装前后包信息、安装载荷校验和最终设置记录。这些日志是本地证据，不是仓库中可下载的附件。

本轮未测试物理 arm64、API29 设备、全部中文输入法候选词矩阵、厂商后台限制、连续 7 天试用或全新机器从空缓存重建。该Android构建子任务没有重跑完整core/server/公网同步验收；整合分支另行执行的联调和公网检查见[官网发布记录](../website-deployment.md)。没有验证 Windows 原生 JNI 构建。两种 ABI 构建和 ELF 对齐通过不能替代 arm64 真机验收；模拟器的可见 IME 与 composing span 测试不能替代所有输入法。以上限制不因 GitHub Release 附件补齐而视为完成。
