原始日志及合成测试图像放本机忽略目录`.local/release-021/`，不提交个人笔记、凭据或私有环境。CI所有测试job和构建job分别核对；草稿不触发公开后的catalog/官网部署。真实升级、签名和未执行项按实际证据回填。

原生测试发现并修正：外层DockedSearchBar拉伸后InputField仍保留默认360dp，因此两者都显式fillMaxWidth；额外上下边距会压缩小高度横屏输入，因此只保留左右16dp。宽屏小高度的IME可占满结果区，仪器用平台API收起IME后检查展开结果，不把这种环境下的整套软键盘可见矩阵记为已通过。测试未削弱布局/命中/按钮断言，修正了可访问图标需要上溯至可点击父按钮的测试驱动。
