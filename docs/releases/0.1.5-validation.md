# 0.1.5 三端构建、整合与发布

日期：2026-11-13。当前状态：0.1.5 已公开发布，Windows 签名目录和官网已上线；Android 正式签名 APK 待后补。来源为 `codex/0.1.5-release-integration`，包含发布基线 `1c9a102`、原更新器 `9d52aea`、整合 `31f7874`、评审修复 `59a5609`；可编译输入归档于 `109ad33`（后者同时记录下一版本规范）。

## 范围与授权

维护者本轮授权冲突整合、独立子代理评审、Windows/Android/Linux 打包及 GitHub 发布；Android 原证书本机不可用，明确允许先发布独立 debug 和 unsigned 构建资料。Linux 使用其已打开的 Ubuntu 24.04 VM；Web 继续暂缓。0.1.6 多选、左滑、撤销和单个 Markdown 导入仅[固化规范](../../spec/client-0.1.6.md)，未写入本版运行功能。

协议 2、local schema 3 和服务端 schema 2 保持；不部署新的账号服务或修改已发布迁移。Linux DEB 明确关闭 updater artifacts，不将 Windows 私钥复制到 VM。未签名 Android 不进入稳定目录，也不替换官网正式 APK。

## 整合与独立评审

原 main 与更新分支的 8 处冲突均为文档冲突。保留 0.1.4 正式发布、协议 2 部署与交叉评审记录，同时注明 0.1.5 增量。

独立 [core 评审](../reviews/client-0.1.5-core-review.md)发现损坏更新状态可能被安装失败错误覆盖并重置序号，已保留 `UPDATE_STORAGE` 屏障并加回归（修复前真实失败、修复后通过）。新增真实 SQLite 测试验证三个空间 checkpoint、忙读事务失败后解锁、较新输入与不可变 outbox 保全。

独立[平台评审](../reviews/client-0.1.5-platform-review.md)发现 Android journal 已写但系统会话未提交时重启锁死，以及解除安装屏障后前台状态丢失/竞态。现核对会话提交状态、提供不依赖确认 Intent 的取消入口，并在恢复时提交最新生命周期状态；实现修复已独立复核。实际仪器结果在下方补记，不以审查代替执行。
