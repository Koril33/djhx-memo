# 0.1.11 构建、测试与发布记录

- 状态：**开发与本地测试完成，CI 发布待执行**。行为见 [版本规范](../../spec/client-0.1.11.md)，设计见 [快捷键设计](../shortcuts-design.md) 与 [搜索功能详细设计](../search-design.md)。
