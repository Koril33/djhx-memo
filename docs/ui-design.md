# 0.1.1 界面预览设计

本版根据项目负责人的讨论结论采用纸白、墨灰与少量品牌绿，先提供可安装版本观察真实使用效果。行为约束见 [产品规范第 11 节](../spec/product-v1.md#11-011-界面预览轻量与统一)；本文说明视觉和布局取舍，不另行定义同步与数据行为。

## 共同视觉

| 语义 | 浅色 | 深色 |
| --- | --- | --- |
| 画布 | `#F7F6F2` | `#1D211F` |
| 内容表面 | `#FCFBF8` | `#242A26` |
| 正文 | `#292E2B` | `#E7EBE6` |
| 次级信息 | `#6B726B` | `#A5AEA5` |
| 操作强调 | `#3D7963` | `#91BBA7` |
| 分隔 | `#E5E7DE` | `#373E38` |
| 选中 | `#EAF0E9` | 采用深色语义表面的同系选中色 |

使用系统字体、4/8 倍数间距、清楚的正文行高和细分隔。品牌绿集中用于主要动作、焦点和选中提示；提示、警告与失败有独立语义。正文优先可读，不能通过过低对比度追求“轻”。大段装饰文字、重复标语、强阴影和嵌套卡片退出主界面。

界面操作统一采用同一份 [Lucide 源图标](../assets/ui-icons/UPSTREAM.json)，2 单位线宽；桌面常用 20px，移动端 24dp。图形尺寸与点击范围分离，按钮至少桌面 36px／移动 48dp。本地化操作名供提示及读屏；设置与菜单允许简短文字，减少猜测。图标来源、许可与生成见 [ADR-0011](adr/0011-offline-interface-icons.md)。应用 Logo 继续遵循[品牌规范](brand-guidelines.md)。

## 移动端

列表页常驻搜索和笔记，标题一行、摘要一行，时间为次级信息；新建入口靠近底部。顶部紧凑呈现品牌与空间标识，低频的回收站、导出、设置进入菜单。

编辑页以正文为中心，保留返回、空间短名、预览切换及更多入口。删除、恢复与导出通过上下文菜单提供；键盘出现时正文避让，移除原全局底栏。切换主题、语言或预览不丢失正在输入的正文与组合 span。

设置按展示偏好、空间账号、设备和数据操作组织。字段保留短标签，注册、导入、注销等操作保留必要确认；普通操作不附常驻教程。

## 桌面端

紧凑导航、笔记列表与编辑器构成主体；DJHX Memo 品牌保留在列表顶部。新建、搜索和主编辑模式容易触达，低频动作收进菜单。笔记条目使用整齐文本行与轻选中底色。

本地保存和云同步采用紧凑状态，展开后可分别查看实际含义、最近同步和主动重试。服务器完整地址及编码等详情退出主界面；本轮保留底栏一处紧凑字数，待实际反馈决定是否进一步收起。保存失败、冲突、凭据失效和恢复处理继续明确显示，不能隐藏为普通成功图标。托盘不可用时保留窗口关闭结果的短提示。

## 预览检查

使用明确的演示笔记检查列表、编辑、搜索、更多菜单、设置、浅深主题及中英文；截图只展示演示内容。安装包须检查原签名/身份与旧数据保留。实际结果、截图和未验收项记录在 [桌面 UI 预览验证](desktop-ui-preview-validation.md) 与 [Android UI 预览验证](android-ui-preview-validation.md)，不能把预览效果等同于全部 v1 发布验收。

## 0.1.6 列表操作

本轮参考[Gmail批量选择/左滑删除](https://support.google.com/mail/answer/7401?co=GENIE.Platform%3DAndroid&hl=en)、[Material上下文操作栏](https://m2.material.io/develop/android/components/app-bar-layout/)和[Snackbar](https://m3.material.io/components/snackbar/overview)，沿用产品已有纸白/炭灰、品牌绿与Lucide图标，不引入运行时UI依赖。

桌面在列表顶部直接显示“选择”，进入后以同一高度的上下文栏提供退出、数量、全选和红色删除图标；条目左侧为对齐的选择标记，标题/摘要/日期保持同列，不使用Unicode方框代替控件。Android长按后以退出/数量/三态全选/删除替换普通顶栏，选择框与正文横向对齐，不额外占一行。两端删除成功以紧凑、对比清楚的底部Snackbar提供撤销，避免再显示重复成功提示。无障碍名称和禁用状态与操作范围一致；busy/IME/原空间屏障不因视觉调整削弱。

## 0.1.8 控件与设置整理

按[本轮规范](../spec/client-0.1.8.md)，桌面多选入口改为与刷新同级的 ListChecks 纯图标；标签改由提示与读屏提供。删除继续使用 Trash，持续显示低饱和红底，彻底删除确认使用强危险色与配对前景色；回收站导航改为 Recycle，导入/导出分别用 FileInput/FileOutput。

已有账号时优先展示空间列表，登录注册收进“添加账号”；失效会话单独提供固定服务器/用户名的“重新登录”。保存与同步详情使用状态图标、右上角关闭，底部空间设置和同步并排且允许换行。本机空间不显示无效同步操作。

更新页沿用现有颜色与字体，按版本状态、候选版本/进度/错误/主操作、自动更新偏好分组。删除常驻安装说明，必要授权/确认仍在相应步骤出现。主操作等待真正命令回执，关闭重开设置也不丢失等待状态。实际目标系统验证以[发布记录](releases/0.1.8-validation.md)为准。
