# 0.1.0 自用候选版使用说明

这是未正式发布的候选版本。实际验收范围见 [验证记录](validation.md)；物理 arm64 Android、完整系统/输入法矩阵与连续 7 天日常试用仍待完成。

## 安装客户端

构建产物保存在编译机的 `dist/`，不提交 Git；下载或复制后先核对同目录 SHA256SUMS。

| 系统 | 文件 | 安装方式 |
|---|---|---|
| Windows x64 | `dist/windows/djhx-memo-0.1.0-windows-x64-setup.exe` | 运行安装程序，默认当前用户安装；依赖 WebView2，缺失时配置为运行随包引导程序下载 |
| Linux amd64 | `dist/linux/djhx-memo-0.1.0-linux-amd64.deb` | 在仓库根目录运行下面的 apt 命令，安装 WebKit/AppIndicator 运行依赖 |
| Android | `dist/android/djhx-memo-0.1.0-android.apk` | 将 APK 复制到设备并安装；包含 arm64-v8a 与 x86_64，Android 10+ |

```sh
sudo apt install ./dist/linux/djhx-memo-0.1.0-linux-amd64.deb
```

Windows 包尚无代码签名证书；版本和文件来源以本机校验值为准。Linux GNOME 的托盘需要 AppIndicator 支持；无法确认托盘可用时，客户端采用普通窗口模式并说明关闭后退出。

## 第一次记笔记

打开后直接在本机空间新建，无需账号或网络。文字自动保存；“已保存到本机”表示本地事务成功，“已同步”表示云端同步完成。保存失败时保留编辑器内容，可重试、复制救援或另存新笔记。

源码编辑支持 Markdown；预览中的任务可勾选。HTML 展示为文字，外部图片不会自动加载，安全链接交系统浏览器打开。搜索支持一字中文；删除进入回收站，正文保留。回收站中可恢复或仅导出回收站内容；正常笔记列表导出活跃笔记 ZIP。

桌面关闭窗口先保存，再隐藏到可用托盘；托盘菜单可以打开、新建、同步和退出。菜单退出只等待本地保存，不等待联网上传。Android 回到前台立即补同步，后台由系统尽力调度。

## 接入自有服务器

候选服务根地址为 `https://memo.djhx.site`，客户端账号设置直接填写此地址，不追加 `/v1` 或 `/healthz`。它提供同步 API，浏览器中没有网页版笔记界面；[健康检查](https://memo.djhx.site/healthz) 正常返回 `{"status":"ok"}`。首次注册的一次性邀请码由管理员单独交付，不在仓库或安装包中。

自建其他实例时，服务端包 `dist/server/djhx-memo-server-0.1.0-linux-amd64.tar.gz` 包含静态 Go 二进制、systemd/Nginx 配置、许可证与运维说明。按 [部署、备份和恢复](operations.md) 配置自己的域名和证书；仓库配置当前对应 `memo.djhx.site` 与已有通配符证书。

在客户端账号设置填写 HTTPS 根地址、用户名、密码和设备名，使用管理员生成的一次性邀请码注册。登录后本机空间内容保持独立；需要上传时明确选择复制导入。冲突会保留原笔记并生成副本，设备吊销和注销不会删除本地笔记。

先导出再卸载、清除数据或更换设备。候选版手动安装升级；Android 后续 APK 必须沿用本机保管的同一发布签名密钥。服务端升级前备份，恢复旧库必须停服并轮换 epoch，具体命令以运维说明为准。
