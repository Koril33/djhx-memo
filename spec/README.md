# 协议与契约

本目录用于存放评审后的正式规范，届时将作为实现行为的唯一事实来源。当前仅建立目录，尚未完成 M0 契约设计。

待补齐内容：

- `sync-protocol.md`：同步、冲突、幂等、分页与游标规则。
- `data-model.md`：实体、版本、墓碑、迁移与术语定义。
- `error-codes.md`：稳定错误码与客户端处理约定。
- `openapi.yaml`：服务端 API 契约。
- `conformance/`：与语言无关的同步场景与期望结果。

设计依据为 [项目规划](../djhx-memo-project-plan.md)。规划仍是草案，其中第 6.2 节的“最后到达服务端者胜”与第 6.3 节的“保留服务端版本、客户端内容转为冲突副本”存在差异，需要在正式协议中统一。其余待决策事项也需在相应里程碑落实，不能由占位文档隐式决定。
