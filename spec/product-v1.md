# v1 产品行为

- 状态：v1 验收基线；已建立 0.1.0 自用候选实现，完整三端验收与连续 7 天试用尚未完成，v1 未发布。
- 优先级：本文所有必需项均是首个日常使用版本的验收条件，不能以“后续支持”为由跳过某个目标端。

## 1. 平台与范围

| 平台 | 首版基线 | 交付 |
|---|---|---|
| Windows | Windows 10 22H2 x86_64（负责人当前主机）；Windows 11 兼容性另行记录 | 安装包，托盘；依赖 WebView2 的安装与缺失提示需验证 |
| Linux | Ubuntu 24.04 LTS x86_64；GNOME Wayland + AppIndicator 托盘支持 | `.deb`；验证中文 fcitx / ibus；同时做 X11 冒烟 |
| Android | Android 10+，arm64 真机 | APK；x86_64 模拟器供开发验证 |

这些是默认验证基线，不表示其他发行版、架构或旧系统已经兼容。实际设备、Linux 桌面环境及已测结果见 [验证索引](../docs/validation.md)；与基线不同的环境仍须补足对应验证。

必需能力：未登录本机笔记、账号注册登录、自动同步、源码编辑与预览、任务勾选、搜索、回收站、冲突提示、Markdown 导出、设备列表及吊销。托盘仅适用于 Windows/Linux。

独立 Web、Apple、全局快捷键、系统分享、附件、开机自启和自动升级不在 v1。常规编辑器快捷操作（复制、粘贴、撤销）仍需正常工作。

## 2. 首次打开与未登录使用

- 无需联网、账号或服务器地址即可进入“本机笔记”，新建、编辑、搜索、删除恢复和导出均可用。
- 新建先显示空白草稿；首次产生非空白字符后持久化为笔记。已有笔记编辑为空时保留，不自动删除。
- 本机空间与账号空间独立。界面始终标明当前空间，未登录内容不会后台自动上传。
- 离线状态不阻止账号空间继续读写。凭据过期或设备被吊销时，停止云同步，保留全部本地内容，提示重新登录；不自动转移到其他账号。

## 3. 注册、登录与本机笔记导入

服务器地址可配置，首次注册/登录表单默认填写 `https://memo.djhx.site`；保留用户已填写的其他地址，不改写已保存账号的服务器归属。生产要求 HTTPS。邀请码注册为默认方式，邀请码由管理员离线管理命令生成。客户端保留注册入口，填写用户名、密码、邀请码和设备名称；无邀请码时仍可使用本机笔记。密码重置由管理员完成，无邮件/短信体系。

登录成功后切换到该服务器与账号对应的本地空间，首次同步不覆盖本机空间。若存在本机笔记，提供“导入 N 条本机笔记”与“暂不导入”，说明是复制到当前账号。默认选择暂不导入；后续可在设置中主动导入。

- 仅复制未删除笔记，生成新 note ID；原本机笔记保留。
- 同一来源笔记的同一保存代次向同一账号重复导入不得产生重复目标笔记。
- 中断后可恢复；已提交到目标数据库的导入映射与待同步操作同事务落盘。
- 本机笔记后续继续编辑不会与已导入副本联动；再次导入新代次属于新副本，操作前显示数量。
- v1 一次激活一个空间，可在设置中进入本机空间或切换已保存账号。跨服务器、跨账号不自动复制数据。

注册成功或登录成功均签发当前设备凭据，行为见 [auth](auth.md)。注销时清除本地凭据、尽力吊销远程设备凭据并回到本机空间；账号数据库保留。离线注销必须说明远程吊销尚未完成，可从另一已登录设备吊销；不为此在本机保留明文旧 token。再次进入该账号需登录。

v1 不提供自动清库或一键删除账号。卸载、系统清理应用数据或手工删除文件可能移除本地未同步内容，客户端导出与上线前备份是恢复手段。

## 4. 编辑、展示与 Markdown

- 列表标题取正文首个非空行，去掉行首 Markdown 标题标记；最长显示 80 个 Unicode 字符，空内容显示“无标题”。标题是派生展示，不单独同步。
- 列表按有效更新时间倒序、note ID 升序稳定排序。待同步笔记使用本地保存时间，收到权威版本后使用服务端更新时间；设备时钟可能导致展示位置变化，不参与版本裁决。
- 提供 Markdown 源码模式和预览模式。v1 支持段落、标题、强调、链接、行内/围栏代码、有序/无序列表、引用、分隔线及 `- [ ]` / `- [x]` 任务列表；表格、数学公式和复杂扩展暂不保证。
- 桌面源码编辑用 CodeMirror 6，Android 为原生编辑 UI；至少高亮标题、列表、任务项、链接及代码围栏。
- 预览中的任务勾选只修改对应源码中的标记，保留其余文字、缩进和换行；代码块内的类似文字不可勾选。遇到未保存编辑先基于最新本地代次操作，避免旧预览覆盖新内容。
- 原始 HTML 只作为文本展示，禁用脚本、嵌入页面、外部图片自动加载和危险链接协议。允许的外部 `https:` / `http:` 链接交由系统浏览器打开；不授予 Markdown 内容 Tauri 命令权限。
- 文本以 UTF-8 保存、行尾统一 LF，不做破坏性的正文 trim 或 Unicode 归一化。中文组合输入不得被同步更新或语法高亮中断。

## 5. 本地保存与状态

正常输入防抖 300ms 落盘，连续输入最长每 1 秒提交一次；失焦、切换笔记、隐藏窗口、进入后台、正常退出时立即请求 flush。仅数据库事务提交成功后显示“已保存到本机”。系统强杀前尚未提交的输入不承诺恢复，不能把“退后台时再保存”作为唯一保存措施。

界面独立表达两种状态：

| 本地状态 | 含义 |
|---|---|
| 保存中 | 仍有内容等待事务提交 |
| 已保存到本机 | 当前可见代次已提交 |
| 保存失败 | 磁盘满、权限或数据库故障；保留内存内容并提供重试和复制/导出救援 |

| 云状态 | 含义 |
|---|---|
| 仅本机 | 当前是未登录本机空间 |
| 待同步 / 同步中 | 存在待发送或正在同步的操作 |
| 已同步 | 已知远端变化拉取完成、无本地待发内容，显示最近成功时间 |
| 离线 / 失败 | 保留本地操作，网络恢复或重试后继续 |
| 需重新登录 | 同步暂停，本地继续可用 |
| 需恢复处理 | 服务端恢复代次改变，旧数据库已保全 |

“已同步”表示上次同步观察到的状态，不保证未连接设备已经收到数据。同步时若当前笔记存在未提交输入，不替换其编辑缓冲区；先保存并交由 core 按协议保留修改。

## 6. 同步、冲突与删除

前台启动、回到前台、网络恢复、本地保存后触发同步，提供手动重试。前台使用 SSE 更新信号，通知缺失时每 30 秒兜底拉取。Android 后台使用 WorkManager 尽力补同步，不承诺固定时刻执行；重新打开立即同步。

版本不匹配时保持服务端当前笔记，将传入内容保存为独立、可编辑的冲突副本。列表显示“冲突副本”、原笔记关系、来源设备、冲突发生时间。标识来自元数据，不修改正文首行。原笔记已删除时保持删除状态，修改内容放入可见副本。过期删除不得静默删除更新后的笔记，显示“删除未执行，内容已保留为冲突副本”。详细规则见 [同步协议](sync-protocol.md)。

删除移入回收站，正文与墓碑均保留，v1 不自动清理或提供永久删除。恢复是基于已知版本的正常修改；恢复与远端编辑冲突同样保留副本。普通搜索排除回收站，回收站可单独查看、恢复和导出。

## 7. 搜索与导出

搜索为本地、字面子串匹配，支持 1～2 个中文字符、英文及混合文本，不把用户输入解释成 FTS 布尔表达式。英文仅保证 ASCII 大小写不敏感，其他 Unicode 按原字符匹配；v1 不做拼音、模糊或词义搜索。

使用 FTS5 trigram 为适用查询加速；短词及无法保证相同语义的查询回退到参数化子串检索。FTS 是可重建索引，笔记提交与索引更新同事务，所有结果过滤 `deleted=false`。SQLite 明确说明 trigram 全文查询不匹配少于三个字符的子串，参见 [官方说明](https://www.sqlite.org/fts5.html#the_trigram_tokenizer)。

离线即可导出当前空间的全部未删除笔记，也可单独选择回收站。每条使用稳定文件名 `<note-id>.md`，UTF-8/LF，附 manifest 记录标题和冲突元数据；输出为 ZIP。导出不覆盖用户任意路径中的既有文件，失败报告具体原因。导出包含已提交的待同步内容；先 flush，失败时提示部分内容尚未落盘，不显示全部导出成功。

`manifest.json` 使用 format_version=1，包含 exported_at、source_kind（local/account/server/recovery）和 notes 数组；每项含 id、file、派生 title、deleted、conflict。file 只能为对应 UUID 加 `.md`，禁止路径分隔符；不包含密码、token、邀请码或绝对本地路径。服务端导出使用同一格式。v1 仅保证导出可读和完整，不提供任意 ZIP/Markdown 的通用导入器；本机及恢复空间复制属于应用内部流程。

## 8. 托盘与窗口

Windows/Linux 托盘菜单至少包含“打开主窗口”“新建笔记”“立即同步”“退出”；未登录时立即同步项禁用并显示仅本机。关闭窗口默认保存后隐藏到托盘；菜单退出先 flush 成功再退出，无网络时不等待上传完成。

Linux 使用菜单恢复窗口，不依赖托盘图标左键事件。基线 GNOME 需具备 AppIndicator 扩展和相关运行库；安装说明写明这些依赖。托盘初始化失败或不确定其可用性时禁止静默隐藏窗口，改为正常窗口模式并提供“关闭后退出”的明确说明；保存失败阻止常规退出并提供救援操作。[Tauri 官方说明](https://v2.tauri.app/learn/system-tray/)指出 Linux 不支持与其他平台相同的托盘图标点击事件。

## 9. 日常可用验收

三端分别完成未登录离线编辑、正常退出重开、Markdown 与中文输入、搜索、回收站和导出。三端登录同一账号完成互相同步、冲突、断网重试和设备吊销。本机导入失败后可恢复且不会自动上传到错误账号。

在记录的参考设备上，以 1,000 条笔记、每条平均 2KiB 验证：冷启动到可输入 P95 ≤2 秒；已提交笔记打开和常用搜索 P95 ≤200ms；无存储故障时从输入到本地提交最长约 1 秒。性能数据须记录样本数、系统和设备，不用单次截图代替测量。

两端前台、连接健康、服务端可达、单条修改 ≤64KiB 时，从本地保存成功到另一端可见 P95 ≤5 秒；SSE 断开后的兜底同步目标 ≤35 秒。后台、休眠和断网恢复另测，不纳入五秒承诺。Android 周期后台任务最短间隔为 15 分钟且受系统调度影响，参见 [Android 官方说明](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)。

发布条件与连续 7 天自用记录见 [validation](../docs/validation.md)。

## 10. 品牌、语言、外观与时间显示

- Windows、Linux 和 Android 的应用名、桌面窗口标题、启动器名称及界面品牌统一为 **DJHX Memo**，不随语言切换；桌面左上角仅保留这一个品牌文字，不显示“简”字徽标、“简记”或重复副标题。包标识、数据目录、Android application ID、凭据服务标识及安装升级身份保持稳定。
- 应用设置提供“跟随系统 / 简体中文 / English”。默认跟随系统，中文系统使用简体中文，其余语言回退英文；选择持久保存于本设备，重启有效。两种语言覆盖常用界面、设置、表单校验、空状态、状态提示、确认对话框、可访问名称及桌面托盘菜单。语言切换即时更新界面，不改写笔记正文、账号名称、设备名称或同步数据。
- 外观提供“跟随系统 / 浅色 / 深色”，默认跟随系统。显式选择优先于系统；跟随系统时动态响应系统明暗变化。列表、编辑器、Markdown 预览、设置、对话框、输入控件、选中/悬停/焦点状态与滚动区域均使用同一主题，避免深色界面中的固定浅色大块。选择按本设备持久保存。
- 时间展示默认使用 IANA 时区 **Asia/Shanghai（UTC+08:00）**，与界面语言独立；设置允许选择上海、UTC 或系统时区。笔记列表、详情、设备最近活动、同步/冲突时间等用户可见时间均按所选时区和语言格式化。存储、协议与导出中的时间仍保留原有 UTC 语义，不修改排序、版本判断或同步规则；不调整操作系统时区。
- 桌面设置弹窗的关闭图标在固定点击区域中居中完整显示，具有本地化可访问名称与可见焦点；窄窗口、两种语言和两种主题下不裁切。Esc 与原有关闭行为保持可用，关闭设置不触发应用退出。
- Android 中文搜索提示仅为“搜索笔记”，英文为“Search notes”；不在搜索占位符中加入实现说明。
- 所有平台图标来自同一份可编辑母版，以当前桌面图标的绿色圆角底、浅色折角纸张及三条横线为基准。提供桌面小图标/安装器、Android 传统/自适应/单色图标所需衍生资源；设计说明记录颜色、构图、留白、尺寸、平台遮罩和统一更换步骤。不得分别手工维护彼此无关的图标。

## 11. 0.1.1 界面预览：轻量与统一

本次小版本仅调整客户端展示与入口布局，先交付可安装预览供实际使用反馈；不增加同步能力、不改变数据归属、保存规则或既有安全确认。

- 三端采用纸白、墨灰与少量原品牌绿色。深色为炭灰与柔和浅字；正文对比清楚，选中、悬停与焦点可辨。系统字体、间距、细分隔与克制圆角形成层次，避免大面积装饰和重复容器。
- 常用动作采用同一套随应用携带的线性矢量图标，离线可用；不再使用字体字符或 emoji 代替界面操作图标。移动端图标点击区域至少 48dp，桌面常规图标按钮至少 36px；有本地化可访问名称，移动端支持长按提示、桌面支持悬停提示。应用 Logo 沿用第 10 节的独立品牌母版。
- Android 列表页保留简洁顶栏、搜索、列表与靠近底部的新建入口。回收站、导出与设置进入明确可找到的菜单；列表以标题、一行摘要及次级时间为主。当前空间始终有简短标识，可进入空间设置，不常驻完整服务器地址。
- Android 编辑页以正文为中心，顶栏提供返回、预览/源码和更多操作；不显示重复应用标题，不保留全局回收站/导出/新建底栏。键盘出现时正文区域正确避让。删除、恢复、导出等原有操作在上下文菜单可达，不更改其作用范围。
- 桌面以笔记列表与编辑器为主体，原有宽功能侧栏改为紧凑导航。保留 DJHX Memo 品牌文字、搜索与容易触达的新建；低频操作收进有清晰名称的菜单或设置。支持现有最小窗口宽度，列表、编辑器和设置在中英及两种主题下可用。
- 正常保存和云同步采用安静的紧凑状态，展开后仍能分别查看本地状态、云状态及最近同步时间，且不把待保存或失败显示为成功。仅本机/账号空间可辨；同步与重试仍可主动触发。保存失败、凭据失效、冲突和恢复处理继续提供可见短提示及操作。
- 普通控件旁移除常驻教程、装饰性标语和重复解释；表单保留短标签，错误、危险操作与数据复制确认保留必要事实。设置按展示、空间账号、设备及数据操作分组，移动端避免把全部表单与设备长列表挤在同一屏。
- 继续支持中文/英文、浅色/深色/系统外观与显示时区；调整布局不得销毁正在输入的编辑器、丢失组合输入/撤销或绕过保存后切换流程。实际安装与验收结果分别记录，不把 UI 预览等同于 v1 发布完成。
