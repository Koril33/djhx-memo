# 注册、登录与授权

状态：v1 未发布契约；已实现账号与设备鉴权，实际安全检查及独立评审见 [服务端验证](../docs/server-validation.md) 与 [评审记录](../docs/reviews/server-review.md)。

## 1. 注册与账号

- v1 支持客户端注册入口，默认要求管理员生成的一次性邀请码；没有公开免邀请注册。
- 用户名使用 3～32 位小写 ASCII 字母、数字、下划线或连字符，首位为字母或数字，服务端不自动改写输入。
- 密码为 12～128 个 Unicode 字符，不 trim，不强制特殊字符组合；客户端不长期存储密码。
- 邀请码由至少 128 位密码学随机数生成，服务端仅存 SHA-256 哈希；默认 7 天过期，可提前吊销，不可重复使用。
- 注册请求包含用户名、密码、邀请码、客户端生成的 device_id 和设备名称。账号创建、邀请码消费和首个设备凭据在同一事务完成。
- 注册响应丢失时，客户端提示尝试以相同账号密码登录，不自动再次消费邀请码。邀请码消费失败不得留下半个账号。
- 用户名冲突可返回 USERNAME_TAKEN；错误、日志和限流记录不得包含密码、邀请码或 token。

## 2. 登录与设备

登录包含用户名、密码、device_id、device_name。新设备使用新 UUID；已保存的同服务器同账号空间复用本设备 ID。设备 ID 已属其他用户时拒绝，不暴露归属信息。

密码正确后，签发 32 随机字节的 base64url 不透明 Bearer token，只返回一次明文。服务端仅存其 SHA-256 哈希，默认有效期 90 天，无滑动延长和 refresh token。重新登录该设备替换旧凭据并清除该设备的吊销状态，其他设备不受影响；用户名密码始终是重新授权的前提。

响应含 user_id、username、device_id、token、expires_at、epoch、protocol_version。token 以 Authorization 请求头传递，不进入 URL、正文日志、错误详情或 SSE 查询参数。凭据本地保存要求见 [数据模型](data-model.md)。

每个数据请求验证 token 未过期、设备未吊销，从 token 推导 user_id。客户端传入 note_id、device_id、cursor、op_id 均不能绕过账号条件；跨账号 ID 按不存在处理。SSE 会话在吊销后应断开，其他 API 下一请求立即失效。

## 3. 注销、吊销与找回

- logout 吊销当前设备；客户端即使离线也能本地退出，数据保留，远程吊销未完成需明确显示，见 [产品行为](product-v1.md)。
- 已登录设备可列出本账号设备，吊销指定设备，也可吊销自己；重复吊销同账号设备返回成功。
- 吊销不远程删除设备本地数据；在该设备下次联网前也不能保证其已察觉。察觉后停止同步，本地编辑和导出继续可用。
- 密码遗失由服务器管理员在本机管理命令中重置，并吊销该账号所有设备；无邮件、短信和公开重置接口。命令不得把明文密码写入 shell 历史，实施时使用交互式输入。
- 不提供 v1 自助删除账号、永久删笔记和清除云端数据的接口。

## 4. 服务端安全基线

密码使用 Argon2id，初始参数 m=19456KiB、t=2、p=1，独立随机盐至少 16 字节、输出至少 32 字节，按 PHC 格式保存参数。部署时可基于压测提高参数，不能低于基线；验证旧哈希成功后可升级参数。[OWASP 官方基线](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)支持这一最低配置。

登录默认按 IP 和账号分别限流：15 分钟内 5 次失败后暂时拒绝，返回 429 与 Retry-After；账号不存在和密码错误统一 AUTH_INVALID_CREDENTIALS。注册默认每 IP 每小时最多 5 次尝试。阈值可配置，反向代理和应用协同限制请求大小及连接数；只信任明确配置的代理转发头。

生产使用 HTTPS，服务只监听回环或私网，由反向代理终止 TLS。开发 HTTP 仅允许显式开启的调试构建/测试服务器，不自动忽略证书错误。无浏览器客户端，默认不开放跨域 CORS。

v1 无端到端加密，服务端可读取笔记正文；本地数据库依赖操作系统账号和磁盘权限保护，不宣称应用已提供数据库加密。日志允许请求 ID、错误码、时延和实体 ID，不记录正文、认证字段及完整敏感请求。
