## 2. 大笔记的交互与数据不变量

- 支持范围继续遵守正文最大 1,048,576 UTF-8 字节，不截断显示或保存，不降低导入/正文上限来获得性能结果。
- 大笔记可简化/暂停昂贵语法装饰；普通笔记保留现有最低高亮能力。候选阈值 128 KiB UTF-8，属于待测参数，不是已接受的最终实现值；轻量提示只在降级有必要说明时展示，不重复弹框。
- 源码首次打开、连续输入、粘贴和删除都要验证；预览优化不能替代源码页修复。后台解析/惰性预览须覆盖单个巨大段落/代码块，不只覆盖很多短块。
- 高亮和排版只改变展示，保留精确正文、缩进、换行、选区、光标、IME composing span 和撤销。异步结果须核对空间、笔记和缓冲版本，不能覆盖迟到之后的新输入。
- 保存继续使用现行防抖 300 ms、连续输入最长约 1 秒提交及必要 flush；语法防抖不能延长保存周期，也不能把装饰完成当成保存成功。
- 正常 1,000 条笔记、平均 2 KiB 的打开/搜索 P95 ≤200 ms 基线保持。大笔记的候选目标、样本结构与参考设备见开发准备，尚未宣布达标；不能用单次 emulator/debug 测量冒充 release/真机 P95。

## 3. Android 离线与联网请求

### 3.1 Devices 的目标状态

进入 Devices 立即显示页面；请求状态仅作用于设备区域。请求未结束时，返回、关闭设置、其他 tab 和回到本地编辑仍可用，且不绕过保存/安装锁等必要屏障。

| 状态 | 目标行为 |
|---|---|
| 无缓存、加载中 | 区域加载提示；其他导航可用 |
| 无缓存、连接失败 | 行内固定脱敏提示与重试；不弹模态网络错误，不当成空设备列表 |
| 同账号缓存、刷新失败 | 保留上次数据并标记未刷新；不声称实时权威状态 |
| 已有数据、刷新中 | 不闪空；限制重复刷新，不禁用整个软件 |
| 凭据失效 | 区域内提供重新登录入口，云状态如实反映；保留本地笔记 |
| 切页、切空间或会话变化 | 旧请求不得回写新页面/账号，也不得在返回编辑后弹旧错误 |

“无法连接服务器”与“系统无网络”按已知事实表达，不能仅凭网络指示断定服务端可达。首期设备缓存建议仅驻内存，按账号/会话隔离，注销或移除账号时清除；持久化缓存不默认进入本版。

### 3.2 其他入口与安全边界

- 检查设备刷新/吊销、登录/注册、注销、同步、更新检查/下载等入口：请求进度、失败和重试就地反馈，网络读请求不持有全局界面 busy。
- 登录/注册成功前不切到假账号；吊销收到服务端成功回执前不显示完成。离线注销沿用现有“本地清凭据、远端吊销未完成”的明确语义，不悄悄保存明文 token 或排队权限操作。
- 重要确认（永久删除、权限/系统安装确认等）保留；本条不要求一概移除所有对话框。保存失败、冲突、恢复代次和凭据失效仍提供明确处理入口。
- 同一动作合并重复请求；会话、profile 和请求序号隔离晚到回执。协程逻辑取消不等于 JNI blocking HTTP 已停止；真实 I/O 未排空时，原生更新屏障仍遵循既有规则，不因页面离开而提前放行安装。
- 离线提示、刷新缓存和导航状态属于平台交互；同步/冲突/鉴权裁决继续由 core/server 负责，不复制到 UI。

## 4. 编辑页排版

- 自动折行保持同一源码行；单次 Enter 仍保存一个 LF，按现有 Markdown 的段内换行/硬换行标记解释。真正段落按 Markdown 块边界识别，普通段落通常由空行分隔。
- 通过适度的行高和段落视觉留白区分两者，不插入额外空行、不重写 Markdown、不改变 Enter 行为及导出文本，也不把列表项/代码行逐行加成段落间距。
- 桌面及 Android 使用同一语义，不强制相同数值；最终行高、空行显示高度/附加间距须以中英长文、代码、列表、字体缩放和触摸定位比较后确定。
- 视觉间距不得造成光标/选区错位、上下移动跳行、IME 中断或大量全文 span 导致 M2 回归。大文本装饰预算与性能方案共同评估；真实空行仍需可辨识。

## 5. jade-ivory 品牌图标

- 输入为维护者提供的 `logo-jade-ivory.svg`，SHA256 `b597731e5496bb1cd92fac662950668948237bee8fdae93e110eda1c2ae81f65`。它已包含放大的构图，不再以此前 55%/60% 墨绿候选代替该文件。
- 基准颜色：背景从 `#2F7A5C` 渐变到 `#0A3024`，玉白主体 `#F3EFE2`，墨滴 `#14523A`。构图、笔画和圆角按原 SVG，允许必要的平台安全区/小尺寸光学适配，不能各端另画或任意更换配色。
- Windows/Linux 应用、快捷方式/任务栏/dock、安装器图标、Android 传统/圆形/自适应及主题单色入口、官网 logo/favicon 同源更新。Android 主题单色图标仍由系统着色，不承诺显示完整玉白渐变；通知资源继续单色且不新增通知功能。
- 桌面托盘已有黑/白 PNG、RGBA 及系统主题选择逻辑保持；不把彩色母版直接替换它们。原有无法确认面板主题的彩色兜底继续存在，可随彩色应用图标更新。
- Android 自适应层拆分背景和前景，背景满幅，由系统遮罩处理，不能直接复制带圆角的整张图当双层资源。前景及 stroke 按安全区适配，不能保证各平台逐像素同尺寸。
- 主界面、官网既有页面主题/排版和中英文名称不因换图同步改色或改名。包 ID、binary、签名、公钥、数据目录与凭据身份不变。
- 原始 SVG、来源/哈希和必要元信息先归档；sunrise、原素材包和 paper-v1 保留可恢复。通过[固定品牌流程](../docs/brand-change-workflow.md)新增版本化输入和映射，不手改活动派生文件，不通过弱化检查/换应用身份刷新图标。

## 6. Windows 新装目录与升级兼容

| 情况 | 目标规则 |
|---|---|
| 无既有安装、未指定目录，英文安装 | `$LOCALAPPDATA\djhxmemo` |
| 无既有安装、未指定目录，简体中文安装 | `$LOCALAPPDATA\阳墨随记` |
| 发现旧“简记”安装 | 原目录覆盖升级，不随安装语言搬动 |
| 发现自定义目录安装 | 原目录覆盖升级 |
| 新装明确选择目录或传 `/D` | 尊重用户选择，优先于语言默认值 |
| `/UPDATE`、`/NS`、静默/被动或修复安装 | 存在已安装路径时沿用；不因未显示语言页生成第二套安装 |

英文/中文显示名仍为 DJHX MEMO／阳墨随记。安装语言决定新默认文件夹，应用内语言切换不移动文件。兼容 INSTALLIDENTITY/卸载识别键保留“简记”，与新默认目录名分离。

旧安装同时显式传不同 `/D` 的情况不作为隐式目录迁移入口；本版建议拒绝该迁移请求并清晰说明已有安装位置。具体提示/退出路径需在安装器设计中确定，不能静默在新旧两处创建安装。本版不搬动账号数据库和凭据，也不提供旧目录迁移工具。
