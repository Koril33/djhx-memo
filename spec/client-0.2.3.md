## 2 桌面设置说明文本按需展开

- 设置弹窗内全部常驻说明文本——编辑器、空间与账号、登录设备、数据与导出页中的 `lintHelp` / `accountHelp` / `devicesHelp` / `exportHelp` / `copySpaceHelp`——由常驻段落改为被说明控件旁的“ⓘ”图标触发，展开显示完整原文。
- 图标复用现有 `info`（Lucide 线性矢量，离线随包）；点击区域至少 36px，有本地化可访问名称与悬停提示。展开内容为真实文本节点，通过 `aria-expanded` / `aria-controls` / `aria-describedby` 关联到被说明控件，读屏可读。
- 展开不新增模态、不抢焦点、不改变被说明控件的值；Esc、点击外部、再次点击或关闭设置弹窗时关闭。实现复用既有 `details[data-menu]` 内联展开机制，不采用会被滚动容器裁剪的悬浮气泡，也不 portal 出弹窗以破坏既有焦点陷阱。
- 说明文本**内容不得删减**；本条替代 `product-v1.md` §11 第 137 条对“数据复制确认保留必要事实”在设置内常驻呈现的要求，改为按需展开后仍保留全部事实。
- 软件更新页的实时状态、错误与恢复提示（`role="alert"`、更新状态徽标、进度、“正在停止下载并切换来源…”“此架构暂无 DEB”“本包下载来源”）不在本范围，保持常驻可见。

## 3 桌面设置弹窗高度稳定

- 设置弹窗正文区设最小高度，使不同 tab 切换时弹窗高度一致、不跳动；超过最小高度的 tab 继续在正文区内滚动（复用现有 `overflow-y: auto`）。
- 最小高度取整个窗口高度的约三分之二（`min-height: calc(100vh * 2 / 3)`）作为初始值，实测后冻结；不采用对弹窗整体固定高度，不得因此裁切原生下拉选择框或关闭图标（延续 `product-v1.md` §11.1）。
- 滚动条出现/消失不引起正文区横向抖动（`scrollbar-gutter: stable`）；切 tab 后滚动位置不得残留，导致“打开即空白”。

## 4 桌面编辑器工具栏图标化

- 工具栏“对照同步滚动”由文本改为图标 `arrow-down-up`，仍仅在对照（split）模式显示，写同一 `splitScrollSync` 偏好，与设置勾选同源联动；`aria-pressed` 表达开关态，开/关以主题选中样式区分，不引入成对字形。补中英 `aria-label` 与 `title`，不得只保留 `title`。
- 工具栏“格式提示”由文本改为图标 `spell-check`，**保留“打开问题列表”语义**（进入源码模式并展开问题面板），仅在 `markdownLintEnabled` 时显示；补中英 `aria-label` 与 `title`。编辑器内 `.lint-status` 状态条、问题计数、相位文案与“检查一次”入口保持。
- 图标由固定 Lucide 1.70.0 同一源生成；`arrow-down-up` 与 `spell-check` 为新增字形，须按固定提交 `b826f0c` 核实存在后写入 `UPSTREAM.json` 并重跑生成与 `--check`。设置页说明“ⓘ”复用既有 `info`，与“格式提示”的 `spell-check` 语义区分，不混用。不改 `client-0.2.2.md` 的 lint 行为。

## 5 桌面列表多选入口去重

- 桌面列表“更多”菜单移除“选择笔记”项，仅保留列表顶部 ListChecks 图标入口；`selectNotes` 文案继续作为顶部按钮的提示与可访问名称。
- 本条修正与 `client-0.1.8.md` 第 7 条的偏差（该文字入口呈现早已被 ListChecks 替代）；选择与数据边界不变。

## 6 破坏性操作菜单位置（两端对齐）

- 两端“更多/笔记操作”菜单中，破坏性操作（移入回收站、彻底删除）统一置于菜单末尾、与常规项以分隔线区分；恢复类操作留在上部；任一时刻至多一个破坏性项。
- Android 编辑态顺序：查找 → 恢复（仅回收站）→ 导入 Markdown → 导出当前笔记 → 状态 → 设置 → 分隔线 → 删除 / 彻底删除。删除与恢复拆为独立项（不再共用一个槽位）。列表态维持原顺序（设置仍末位、无破坏项）。
- 桌面笔记操作顺序：恢复（仅回收站）→ 复制文字 → 导出当前笔记 → 分隔线 → 移入回收站 / 彻底删除。
- 本条替代两端既有呈现顺序，不改变删除/恢复/导出的作用范围与确认边界。
