# 0.2.1 界面修正契约

- 日期：2026-11-21；基线`v0.2.0 / 4b10ac7`。维护者授权实施、测试并创建`v0.2.1` Release draft；不公开Release或推广官网/更新目录。
- 范围：Windows/Linux空白页精简、Android全局搜索布局。维护者已确认干净Windows安装0.2.0任务栏图标正确，Linux重启后窗口图标与Ctrl+W正常；三项移出修复范围。
- 客户端0.2.1、Android code16；core0.1.13、server0.1.4、协议2、local schema4/server schema2保持。继承[0.1.13](client-0.1.13.md)、[0.2.0](client-0.2.0.md)和[自动更新](automatic-updates.md)未被本条替代的行为。

## 1. 桌面空白页

- 仅空白页删除顶部文件图形、“文字先留在你身边”标语、可视“笔记编辑器”标题，以及关闭行额外的保存后隐藏/退出说明。编辑/草稿标题、列表折叠与空间入口保持；区域可访问名称保留。
- 三行统一背景、边框、圆角、间距、键帽、悬停与焦点风格：新建笔记Ctrl+N、全局搜索Ctrl+Shift+F、关闭窗口Ctrl+W。中英文及浅深主题一致。
- 三行均为可通过鼠标、Enter或Space激活的按钮。空白页关闭操作复用`request_hide`及现有生命周期/保存确认链；busy、booting、过渡、模态及生命周期pending时不得重复发起。
- 两段式Ctrl+W不变：打开笔记/草稿时先安全关闭当前文档并进入空白页；空白页再走原窗口关闭链。IME、重复按键、模态与保存失败保护保持。
- 原生关闭按钮/Alt+F4、托盘恢复、冷启动、切空间/分区、删除与导入打开行为继续按0.1.13执行，不因界面精简重写。

## 2. Android全局搜索

- 收起输入框和展开Surface/提示/结果共用同一外层约束；内容区域左右各16dp外边距。搜索区域在可用宽度中水平居中，宽屏最大宽度720dp；窄屏按可用宽度收缩，不强占组件默认360dp。
- 文字/结果仍按语言方向排布；不把输入文字本身改为居中。结果行内部padding独立于外边距，不逐层重复加边距。
- 保留现有DockedSearchBar、active/系统返回、键盘Search、清除、加载、空结果、错误/重试、滚动、点击打开和来源/回收站标记。
- 搜索仍为本机＋当前选中账号本地副本＋普通回收站；请求锚点、账号隔离、迟到回执保护、排序/匹配/计数不变，不新增过滤器、网络等待或依赖升级。
